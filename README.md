# Elastic Integrations (AI)

A unified, searchable catalogue of official Elastic integrations and community-built custom integrations.

The catalogue currently includes **487 official integrations** and **35 custom integrations**.

Visit the catalogue at [2gavy.github.io/elastic_integrations_site](https://2gavy.github.io/elastic_integrations_site/).

Official entries link to Elastic's public documentation. Custom entries expose only approved public metadata and link authorized users to the protected source repository. This community project is not an official Elastic website and is not endorsed or supported by Elastic.
